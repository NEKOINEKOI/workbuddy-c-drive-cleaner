# 通用清理提示词（交给任意 agent 自己执行）

这段提示词给「非 WorkBuddy」的 agent 用。把它整段复制给那个 agent（Codex、Claude、Cursor、DeepSeek 或其他），它会用自己的原生能力扫描自己的数据、按同一套流程清理。**一次只处理一个 agent**；不要把这段词同时发给多个 agent。

WorkBuddy 本身不用这段词，走仓库里的脚本流程。

---

## 提示词正文（整段复制）

```text
帮我整理我这个 agent 在自己数据目录里产生的占用。注意：不是扫描整块 C 盘，也不是整理别的软件——只扫你自己这一个 agent 的数据目录，范围外的文件一概不碰。严格按下面的流程做，全程先只读扫描、先跟我确认，再动手。

【一条铁律】一次只处理你自己这一个 agent。不要顺手扫别的 agent，不要把多个 agent 的目录混在一起。清完你自己之后，我再决定要不要换下一个。

【第 1 步 · 只读扫描】
先确定你自己这一个 agent 的数据放在哪（通常在用户主目录 ~/.<你的名字> 和 AppData 下，你自己最清楚），只对这一个目录做只读扫描，不要扫整块 C 盘、不要扫别的 agent 或别的软件。按目录列出：完整路径、大小、大概用途、最后修改时间。不要因为一个目录大就判定它是垃圾——体积不等于可释放空间。

【第 2 步 · 分四类列成表，先跟我确认】
把扫描结果分成四类，列成表给我看：
1. 可删除：自动重建的缓存、旧日志、临时文件、过期下载。说清楚删了会不会影响使用。
2. 可迁移：停用很久、搬走也照样能用的冷数据或项目目录。说明多久没动、搬走后是否还能用。
3. 必须保留：运行时/程序本体、技能、插件、数据库、配置文件、登录凭据、正在用的会话和历史。逐项说明删了会丢什么。
4. 拿不准的：标注「需单独调查」，一律不动。
表尾给我三个实测数字：能删多少文件多大、能迁多少目录多大、全部处理完理论上能腾多少。数字必须是实测的，没测就写「未测」，不要编。
然后问我：哪些删、哪些迁、哪些留。我不确认，你不要动任何文件。

【第 3 步 · 问两个位置】
开始动手前问我：
1. 待删包放哪：删下来的东西在 C 盘拢成一个文件夹给我手动删。我没给路径就默认放 C 盘用户主目录下的一个专门文件夹。
2. 迁移到哪：要搬走的东西放哪个盘哪个文件夹。没给就默认放 D 盘下你名字对应的文件夹。目标盘不存在就让我换。
我先确认这两个位置，你才动手。

【第 4 步 · 迁移：先复制，后打包源】
对我确认要迁的目录：先复制到目标盘 → 校验文件数和字节数完全一致 → 才把 C 盘原目录打包成文件夹 → 出一份清单（原路径对照表）。任何一步失败就跳过、记下路径和原因，不要反复重试、不要提权。搬走的是现在没在用、搬了也不影响使用的；正在用的一律留。

【第 5 步 · 清理：只攒包，不直接删】
对我确认要删的文件：只把它们移到第 3 步说的那个待删文件夹里，生成一个原路径对照表（能照着还原）。你自己永远不要直接删除文件——攒成包、把文件夹完整路径给我，由我检查后自己删，这样才真正释放空间。失败一次就跳过、记原因，不提权、不换命令反复试。

【第 6 步 · 交付和收尾】
把待删包和迁移包这两个文件夹的完整路径一起给我，说清楚里面各有什么、一共多少内容。让我自己检查后手动删。
如果里面有文件删不掉——包括我用管理员模式也删不掉——提示我可以打开 CODEX 让它删，或者在 terra 里指定这个文件夹让它清理；你不要自己提权、改权限、换命令硬删。
最后提醒我一句：把你的默认存储位置、缓存目录、下载/输出目录改到别的盘，不然 C 盘还会再涨。只提醒，不要替我改配置；我要改你再单独处理。

【红线】
- 不碰运行时、技能、插件、数据库、配置、凭据、正在用的会话和历史。
- 不删除任何文件，只做暂存和打包，删由我来做。
- 不确定用途的一律不动。
- 一次只处理你自己，清完问我要不要换下一个 agent。
```

---

## 交付方式

用户说「我要清 Codex / Claude / 别的 agent」时：

1. 默认仍是 WorkBuddy——用户没点名就不切。
2. 用户点名后，**把上面的提示词正文整段给他**，让他粘贴到那个 agent 的对话里。
3. 说明一句：这套流程和配置 WorkBuddy 是同一套，只是换成那个 agent 用自己的能力清自己的位置；一次清一个，清完再清下一个。
4. 收尾提示都在提示词里（改默认存储位置、删不掉用 CODEX/terra），不用额外补充。

`agents/registry.json` 和 `Scan-Agent.ps1` 是可选的只读参考：需要快速知道某个 agent 大概有哪些目录、默认存储位置该往哪改时查一下；**不是清别的 agent 的必经步骤**，主线是把提示词交给对方的 agent 自己扫。
